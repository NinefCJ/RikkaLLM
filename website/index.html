项目介绍

一个把能力收回设备端的 AI 客户端

RikkaLLM 是 RikkaHub 的下游分支，在保留多服务商对话、助手隔离、MCP、Proot 工作区等能力的基础上，重点向本地推理与开发者工具链两个方向扩展。

它不依赖任何云端账户即可运行本地模型，消息、代码与工具结果都留在你的设备上；同时内置轻量代码编辑器、对话图谱与模型市场，让手机也能成为一台随身开发终端。

核心功能

从对话到开发，一台设备搞定

多服务商对话

OpenAI、Gemini、Claude 及任意 OpenAI 兼容端点，同一界面无缝切换。

本地推理引擎

内置 MNN 引擎（含 Llama 后端），设备端离线运行大模型，隐私自主。

内置代码 IDE

编辑器、文件树、命令面板与外接键盘快捷键，手机上也能写代码。

对话图谱

Thoughtdag 将对话结构可视化为图谱，随对话自动同步并持久化。

模型市场

从 HuggingFace / ModelScope 发现模型，设置中一键选用，免手动配置。

工具与工作区

支持 MCP 与 Proot 沙箱，AI 可调用文件读写与 Shell 执行等扩展工具。

生成式 UI

工具结果以结构化卡片呈现，经清洗防注入，告别纯文本堆叠。

语音与多模态

TTS / STT 语音能力，以及图片、文档（PDF/DOCX/PPTX/EPUB）输入输出。

使用说明

四步上手

  1. 01

    安装应用

    下载 APK 并在 Android 设备上安装（需允许「未知来源」安装）。

  2. 02

    配置服务商或本地模型

    在「设置 → 服务商」填入 API Key；或准备 MNN 依赖后添加本地模型端点。

  3. 03

    开始对话

    新建或选择一个助手，配置系统提示与参数，输入消息并附带图片 / 文档。

  4. 04

    启用进阶能力

    开启网页搜索、工作区工具，或进入内置 IDE 连接外接键盘编写代码。

MNN 本地引擎需先准备 vendor/MNN 与预编译 libMNN.so（见仓库 scripts/setup-mnn.*）。
