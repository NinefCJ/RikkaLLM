# 05 · 功能列表

> 按模块列出具体功能点，标注优先级（P0 必备 / P1 重要 / P2 增强）与依赖关系。优先级用于排期，依赖关系用于确定实现顺序。

---

## 优先级定义
- **P0**：构成"DAG 上下文图 + 轻量画布"最小可用闭环，必须实现。
- **P1**：显著提升可用性，应在 P0 之后尽快实现。
- **P2**：增强/锦上添花，可后续迭代。

---

## 模块 M1 · GraphModel（DAG 核心模型）

| 功能点 | 优先级 | 依赖 | 说明 |
|---|---|---|---|
| 定义 `GraphNode` / `GraphEdge` 领域类 | P0 | 无 | `kind`/`sourceRef`/`state`/`position` |
| `sourceRef` 到 `MessageNode`/`UIMessage` 映射器 | P0 | M1 | 图与现有消息解耦互转 |
| 拓扑遍历 `topoOrder(target)` | P0 | M1 | 按入边收集祖先序列 |
| 无环校验 `isAcyclic()` | P0 | M1 | 写入边时校验，防环 |
| 图增量合并（流式建图） | P1 | M1 | 复用 `mergeChunk` 思路 |
| 节点缓存（避免重复遍历） | P1 | M1 | `O(V+E)` 性能保障 |

## 依赖关系图（实现顺序）

```
M1(模型) ──► M5(持久化) ──► M6(VM+DI)
   │              │              │
   └──► M2(装配器)┴──► M3(编排) ──┘
                          │
                          ▼
                       M4(画布) ── 依赖 M1/M2/M3/M5/M6
```

**建议排期**
1. **P0 闭环**：M1 → M5 → M6 → M2（装配可运行）→ M3(Branch/Prune/Inspect) → M4(画布+手势)。
2. **P1 增强**：Merge、Inspect diff、provenance、Tool 内核复用、画布菜单。
3. **P2 锦上添花**：导出、自动多步编排、流式建图缓存。

> 注：包体积增量预计 < 0.5MB（仅新增 Kotlin/DEX，无新 native/大型资源），详见总索引 README 的"轻量化约束"。
